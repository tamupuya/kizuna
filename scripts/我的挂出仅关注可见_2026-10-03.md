# 中谷店：自己的挂出只在「关注」tab 可见（2026-10-03）

## 需求

**现状**：发布商品后，点开中谷店（推荐 tab）看到的列表里混有自己的商品。
**改动**：自己的挂出只在「关注」tab 可见；**其他任何位置都不可见**。

## 实现

### 1. 新增聚合 getter：`publicListings`

`src/stores/kizuna.ts`：

```ts
// 2026-10-03：广场列表 —— 排除自己挂出的商品
const publicListings = computed(() =>
  listingStore.activeListings.filter(l => l.owner_id !== userStore.currentUserId)
)
```

已加入 return（供所有视图使用）。加在聚合层而非 listingStore，是因为「排除自己」依赖 `currentUserId`（跨 store），放聚合层避免循环依赖。

### 2. 中谷店四个 tab 全部改用 publicListings

`src/views/ZhongguView.vue`：
- `recommendListings`（推荐）：`store.activeListings` → `store.publicListings`
- `filterByTag()`（服饰/道具/谷子共用）：`store.activeListings` → `store.publicListings`
- `followListings`（关注）：本就按 `myFollowingIds` 过滤，天然不含自己，未改

### 3. 「我的挂出」区块：从推荐 tab 移到关注 tab

改动前：`v-if="myTop3.length > 0 && activeTab !== 'follow'"`（在推荐/服饰/道具/谷子都显示）
改动后：`v-if="myActiveListings.length > 0 && activeTab === 'follow'"`（只在关注 tab）

- `myTop3`（slice(0,3) 快览）→ `myActiveListings`（**全部**在售挂出，可搜索过滤）
- 删除「全部 ›」按钮（原本跳 `?tab=mine`，该 tab 已不存在）
- 接通管理操作：`:on-archive` / `:on-restore` 真正调用 `store.archiveListing()` / `store.restoreListing()`（原先传空函数 `() => {}`，下架按钮点了没反应）

### 4. 关注 tab 补全三种空态（互斥）

| 条件 | 文案 |
|---|---|
| 无关注 + 无挂出 | 暂无关注 / 去漫展详情页或其他用户主页关注 ta… |
| 有关注 + 搜索无结果 | 没找到匹配的商品 / 试试换个关键词 |
| 有关注但对方没挂出 | 关注的人还没挂出 / 先去推荐里逛逛其他用户的挂出吧 |

### 5. 支持 `?tab=` 参数直达

`activeTab` 初始值改为读取 `route.query.tab`（白名单校验 5 个 tab 值）。
注意：判断逻辑必须放在 `tabs` 声明**之后**，否则 TDZ 抛错（写第一版时踩到，已修）。

**（重要）还需 watch query**：`App.vue` 的 `router-view` key 是 `r.path`，**query 变化不会重建组件**。
所以从 `/zhonggu` 跳到 `/zhonggu?tab=follow` 时，仅靠初始值不生效，必须加：

```ts
watch(
  () => route.query.tab,
  (val) => {
    const t = String(val || '')
    if (tabs.some(x => x.value === t)) {
      activeTab.value = t as ZhongguTab
    }
  },
)
```

### 6. 发布商品后跳「关注」tab

`src/views/ZhongguFormView.vue` 第 126 行：

```ts
await store.fetchListings()
// 2026-10-03：发布后跳「关注」tab，让用户立刻看到自己刚挂出的商品
// （自己的挂出只在关注 tab 可见，跳推荐 tab 会看不到刚发的商品）
router.push('/zhonggu?tab=follow')
```

依赖上面的 watch 才能生效。

### 6. 其他位置同步过滤

- `src/views/RadarView.vue`（中谷 tab 列表 + 空态判断）：`store.activeListings` → `store.publicListings`
- `src/views/ProfileView.vue`（Stats Row「广场」数字）：`store.activeListings.length` → `store.publicListings.length`
- `src/views/ZhongguDetailView.vue`「编辑挂出」：`/zhonggu?tab=mine` → `/zhonggu?tab=follow`（原 tab 已不存在）

**未改（有意保留）**：
- `DisputeView.vue` / `ZhongguDetailView.vue` 用 `store.listings.find(id)` 按 id 直查 —— 这是「自己访问自己的商品/申诉」，不是列表可见性，必须保留，否则无法管理自己的挂出
- ProfileView「挂出」统计用 `store.myListings.length` —— 统计自己的数量是正确的
